# Safelink 🔗🛡️

**Safelink** adalah layanan pengaman dan pemendek tautan (URL Protector / Shortener) berbasis web yang dirancang untuk mengamankan, memvalidasi, dan mengarahkan ulang URL tujuan dengan lapisan keamanan ekstra sebelum pengguna mencapai lokasi akhir.

---

## 🚀 Fitur Utama

- **URL Encryption & Protection:** Mengenkripsi URL tujuan untuk mencegah akses langsung yang tidak sah.
- **Token-based Redirection:** Menggunakan token berbasis waktu atau sesi sementara untuk validasi proses *redirect*.
- **Interstitial Landing Page:** Menampilkan halaman perantara dengan penghitung waktu (*countdown*) sebelum tombol tujuan aktif.
- **Bot & Abuse Prevention:** Meminimalisir bot/spam melalui validasi perantara dan header keamanan.
- **RESTful API:** Menyediakan endpoint API untuk membuat dan mengelola tautan terproteksi secara terprogram.
